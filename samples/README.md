# Reviewing these samples

This folder is a **code-review extract**, not an application.

1. Start with `types/` — feature lanes and UI props.
2. Read `i18n/` — locale union, tiny PL/EN table, `translate`, `LanguageSwitcher`.
3. Read `ui/` — presentational chips, disabled coming-soon control, feature card.
4. Read `mock/features.ts` — static rows only.

There is no `npm start`, no API, and no encryption implementation here. To see the running product UI, open [https://besafe.lukjohn.com/](https://besafe.lukjohn.com/) or [https://preview.besafe.lukjohn.com/](https://preview.besafe.lukjohn.com/).
